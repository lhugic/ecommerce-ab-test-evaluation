# Оценка A/B-теста интерфейса и проверка гипотез (Python)

## Бизнес-задача
Проект разделен на две аналитические части:
1. **Яндекс Книги (проверка гипотезы):** статистически оценить разницу во времени активности между пользователями из Москвы и Санкт-Петербурга.
2. **BitMotion Kit (оценка A/B-теста):** проанализировать результаты A/B-тестирования нового интерфейса интернет-магазина. Цель редизайна - увеличить конверсию из регистрации в покупку минимум на 3 процентных пункта.

## Стек технологий
* **Инструменты:** SQL (формирование витрин, агрегация), Python (Pandas, Matplotlib).
* **Статистика:** `scipy.stats`, `statsmodels` (t-тест Уэлча для независимых выборок, Z-тест для разности пропорций).
* **Дизайн эксперимента:** расчет мощности теста (80%), MDE (3 п.п.) и оценка репрезентативности выборки.

## Главные инсайты

### 1. Паттерны активности пользователей (Яндекс Книги)
* Разница в среднем времени активности между пользователями Санкт-Петербурга (11.26 ч.) и Москвы (10.88 ч.) оказалась статистически незначимой (p-value = 0.344). 
* География проживания не является главным фактором вовлеченности. Рекомендуется разделять аудиторию по другим признакам (возраст, жанровые предпочтения).

### 2. Качество A/B-теста
* Пересечений пользователей между группами нет, распределение равномерное (4952 и 5011). 
* Фактические размеры групп превысили минимально необходимый порог (3761 человек) для определения эффекта в 3 п.п. при мощности 80% и a=0.05.

### 3. Результаты A/B-теста (конверсия в покупку)
* Конверсия в тестовой группе выросла с 27.81% до 29.54% (абсолютный прирост +1.73 п.п.). 
* Z-тест подтвердил статистическую значимость изменения (p-value = 0.028).
* **Бизнес-вывод:** несмотря на то, что новый интерфейс действительно улучшил конверсию, фактический прирост оказался ниже целевого порога (1.73 п.п. вместо ожидаемых 3 п.п.). Внедрение интерфейса принесет пользу, но не покроет первоначальных ожиданий.

# Оценка A/B-теста и проверка гипотез

## О проекте
Две задачи:
1. **Яндекс Книги** — проверить, отличается ли время активности пользователей Москвы и Санкт-Петербурга.
2. **BitMotion Kit** — оценить A/B-тест нового интерфейса интернет-магазина. Цель редизайна — поднять конверсию из регистрации в покупку минимум на 3 п.п.

## Стек
- SQL — витрины и агрегация
- Python, Pandas, Matplotlib
- SciPy, statsmodels — t-тест Уэлча и Z-тест
- Расчёт мощности теста, MDE и размера выборки

## Главные выводы

**Яндекс Книги**
- Среднее время активности: СПб 11.26 ч, Москва 10.88 ч.
- Разница статистически незначима (p-value = 0.344).
- География не главный фактор вовлечённости. Лучше сегментировать по возрасту и предпочтениям.

**Качество A/B-теста**
- Пересечений пользователей нет.
- Группы почти равные: 4952 и 5011.
- Размер выборки достаточный для обнаружения эффекта в 3 п.п. (минимум было 3761).

**Результаты A/B-теста**
- Конверсия: 27.81% → 29.54% (+1.73 п.п.).
- Изменение статистически значимо (p-value = 0.028).
- **Вывод:** рост есть, но он ниже целевых 3 п.п. Внедрять можно, но ожидания нужно скорректировать.

## Рекомендация
Не запускать интерфейс в полном объёме, если цель — именно +3 п.п. Можно внедрять с пониманием, что реальный эффект будет около +1.7 п.п.
